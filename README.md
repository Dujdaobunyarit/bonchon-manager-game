# Bonchon Manager Meeting Game

เว็บเกมสำหรับการประชุม Manager Meeting หน้าเว็บอยู่บน GitHub และโฮสติ้ง ส่วนรายชื่อ คะแนน และกฎเกมอยู่บน Supabase

| ผู้ใช้ | รหัสผู้ใช้ | เล่นได้ |
|---|---|---|
| Store Manager L5 | รหัสพนักงาน | เกม 1 (เกม 2–3 ดูอย่างเดียว) |
| Area Coach L4 | รหัสพนักงาน | เกม 1, 2, 3 |
| แอดมิน | ชื่อแอดมิน | ควบคุมเกมและจอ projector |

รหัสผ่านอยู่ใน `private/passwords.json` เปลี่ยนแล้วให้รัน `npm run seed` และรัน `private/seed.sql` อีกครั้ง

## Supabase

ติดตั้งแล้วในโปรเจกต์ `bonchon-manager-game` ค่าใน `config.js` เป็นค่าที่อยู่ในหน้าเว็บได้ ห้ามใส่ service_role key

ถ้าติดตั้งใหม่ ให้เปิด SQL Editor แล้วรัน `supabase/schema.sql`, `supabase/storage.sql` และ `private/seed.sql` ตามลำดับ

## ไฟล์ที่ห้ามขึ้น GitHub หรือโฮสติ้ง

`private/` และ `data/` มีรายชื่อพนักงาน รหัสผ่าน และเฉลยทั้งหมด `.gitignore` กันไว้แล้ว ถ้าอัปโหลดไฟล์เองผ่านเว็บ ห้ามเลือกสองโฟลเดอร์นี้

## ขึ้นเว็บ

ตั้งโฮสติ้งให้เสิร์ฟจากโฟลเดอร์หลักของ repo ไม่ต้อง build เปิดจอแอดมินด้วย URL เดียวกับที่แจกผู้เล่น เพราะ QR สร้างจาก URL ที่เปิดอยู่

## ก่อนใช้จริง

- แทนที่ `data/assessment.json` ด้วยชุดประเมินจริงและลบ `"draft": true` รัน `npm run seed` แล้วรัน `private/seed.sql` อีกครั้ง
- อัปโหลด Motion ที่ Supabase > Storage > motions ตั้งชื่อ `s1.mp4` ถึง `s10.mp4`
- กด ⚙️ ตั้งค่า > รีเซ็ตเกมทั้งหมด เพื่อล้างผลซ้อม

รันซ้ำ `private/seed.sql` ได้โดยไม่ล้างคะแนน แต่ถ้าเปลี่ยนจำนวนข้อหรือเฉลยกลางเกมให้รีเซ็ตเกมก่อน

## Export ผลเกม

กดปุ่ม ⬇️ Export บนจอแอดมิน จะได้ไฟล์ Excel ที่แยกแผ่นเป็นสรุปรายคน เกม 1 เกม 2 เกม 3 และสกอร์บอร์ด ควรดาวน์โหลดก่อนรีเซ็ตเกมทุกครั้ง

## ปุ่มลัดบนจอแอดมิน

`Space` หรือ `→` ไปขั้นถัดไป · `B` สกอร์บอร์ด · `F` เต็มจอ · `H` ซ่อนแถบควบคุม

## ทดสอบบนเครื่อง

```bash
npm install
```

```bash
npm run seed
```

```bash
npm test
```

ซ้อมคนเล่นครบบน Supabase จริง คำสั่งนี้เล่นทับเกมแล้วรีเซ็ตทั้งหมด ห้ามรันระหว่างเล่นจริง

```bash
node test/live.mjs
```

ดูหน้าเว็บโดยไม่ต่อ Supabase จริง (เปิดที่ http://localhost:3000)

```bash
node test/dev-server.mjs
```
